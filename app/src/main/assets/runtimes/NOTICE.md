# Notice: bundled Java runtime

`java-21/bin-arm64.tar.xz` and `java-21/bin-x86_64.tar.xz` are copied unchanged from
ZalithLauncher2 (https://github.com/ZalithLauncher/ZalithLauncher2, GPL-3.0),
folder `ZalithLauncher/src/main/assets/runtimes/jre-21/`.

They contain an OpenJDK 21 runtime built for Android. OpenJDK is licensed under
GPL-2.0 with the Classpath Exception. Source for OpenJDK is available from
https://openjdk.org.

The `version` file is the revision of the bundle (ZalithLauncher2 uses `2`). It is used
to decide when the runtime must be reinstalled.
